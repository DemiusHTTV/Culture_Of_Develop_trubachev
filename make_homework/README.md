# Разработка и автоматизация с помощью Make

В данном проекте демонстрируется использование утилиты `make` и файла `Makefile` для автоматизации рутинных задач в жизненном цикле разработки программного обеспечения на Python. Основной упор сделан на создание надежных, воспроизводимых процессов, не зависящих от глобального состояния системы ("stateless"-подход).

## Задачи проекта

1. **Единая точка входа**: `Makefile` предоставляет унифицированный интерфейс для всех частых операций (установка, проверка типов, проверка форматирования, запуск). Разработчику не нужно запоминать сложные команды и их аргументы.
2. **Изолированное окружение (stateless)**: Вместо того, чтобы полагаться на ручную активацию виртуального окружения (`source .venv/bin/activate`), все скрипты в Makefile используют абсолютные или относительные пути к исполняемым файлам внутри локального окружения проекта (например, `.venv/bin/python`). Это защищает от ошибок "случайного" использования системного интерпретатора.
3. **Автоматизация проверок качества**:
   - `make check-requirements`: анализирует импорты в исходных файлах и сверяет их с зависимостями, указанными в `requirements.txt`. Гарантирует, что все используемые пакеты добавлены в зависимости.
   - `make typecheck`: проверяет корректность типов (с помощью `mypy`), предотвращая баги несоответствия типов еще до запуска кода.
   - `make lint` и `make format`: проверяет и автоматически форматирует код (с помощью `black`), поддерживая единый стиль кодирования.
4. **Композиция (цепочки)**: Цель `make check` выполняет всю цепочку проверок (типы, импорты, стиль). Если одно из звеньев завершается с ошибкой, цепочка прерывается.

## Доступные цели (Targets)

- `make venv` — инициализирует виртуальное окружение в папке `.venv`.
- `make install` — устанавливает зависимости из `requirements.txt` в виртуальное окружение.
- `make run` — запускает приложение (`src/app.py`).
- `make typecheck` — запускает статическую проверку типов.
- `make format` — форматирует код в директории `src/`.
- `make lint` — проверяет стиль кода без его изменения.
- `make check-requirements` — выполняет анализ исходного кода для поиска неуказанных зависимостей.
- `make check` — запускает проверки: `typecheck`, `check-requirements` и `lint`.
- `make clean` — удаляет виртуальное окружение и временные файлы кэша.

## Как запустить

1. Убедитесь, что у вас установлен `make` и `python3`.
2. В корне директории `make_homework` выполните:
   ```bash
   make install
   make run
   make check
   ```

Все зависимости будут установлены в `.venv`, после чего отработают приложение и все необходимые проверки. Глобальное окружение вашей системы затронуто не будет!
